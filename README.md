
# AIML Practical Assignment 3

## Title
Implementation of Tic-Tac-Toe Game Using Python

## Problem Statement
Write a Python program to implement a Tic-Tac-Toe game.

## Objective
To develop a command-line Tic-Tac-Toe game for two players
using a 3x3 board.

## Theory
Tic-Tac-Toe is a two-player game played on a 3x3 grid.
Players X and O take turns marking empty cells. The first
player to get three marks in a row, column, or diagonal wins.
If all cells are filled without a winner, the game ends in a draw.

## Features
- 3x3 game board
- Two-player gameplay
- Input validation
- Win detection for rows, columns, and diagonals
- Draw detection
- Automatic switching between players

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

   python tic_tac_toe.py

## Result
The game displays the board after each move and announces
the winner or a draw when the game ends.

## Complexity Analysis
Time Complexity: O(1) per move for checking the win condition.
Space Complexity: O(1) for the fixed 3x3 board.

## Conclusion
The program implements a two-player Tic-Tac-Toe game using
Python functions, conditional statements, loops, and lists.
